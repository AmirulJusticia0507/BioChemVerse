# Agents Configuration

## Rules

1. Sebelum mengerjakan todo, wajib baca file ini dulu.
2. Setiap task selesai wajib langsung commit & push ke remote origin/main.
3. Jangan lanjut task berikutnya sebelum commit & push task sebelumnya selesai.
4. Commit message format: feat|fix|docs|chore: <deskripsi singkat>.

## Workflow

1. Baca AGENTS.md.
2. Baca TODO.md, pilih task pending dengan prioritas tertinggi.
3. Kerjakan task.
4. Update status task di TODO.md menjadi completed.
5. git add -A && git commit -m "..." && git push.
6. Lanjut task berikutnya.

## Agent Roles

- docs-agent: merapikan dokumentasi.
- arch-agent: menjaga konsistensi arsitektur.
- design-agent: menjaga konsistensi design system.
